# Security and privacy

This is a local educational prototype, not an authenticated public service.
Do not upload confidential documents without permission and an appropriate provider
account configuration. Do not commit API keys or private documents. If a key is
exposed, revoke it at the provider and remove it from repository history.

Report suspected vulnerabilities privately to the repository owner. Do not include
credentials or confidential document text in public issues. Before public deployment,
add authentication, rate limiting, HTTPS and proxy-level upload/request limits.
